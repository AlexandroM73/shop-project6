# Магазин (shop-project)

Простой магазин на Django с Bootstrap.

## Технологии
- Python
- Django
- Bootstrap 5

## Установка
1. Клонируй репозиторий
2. Активируй виртуальное окружение: `.\venv\Scripts\Activate.ps1`
3. Установи зависимости: `pip install -r requirements.txt`
4. Запусти сервер: `python manage.py runserver`

## Ветки
- `main` — стабильный релиз
- `develop` — основная ветка разработки
- `feature/*` — ветки для задач
